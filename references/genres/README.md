# Genre knowledge packs

Optional genre-specific notes belong here, for example `jpop.md`, `galgame.md`, `jrpg.md`, `chiptune.md`, `jazz.md`, `rock.md`, or `ambient.md`.

Create a pack only when a task provides reliable sources or specifically requires research. A genre pack should add idiomatic decisions—form, groove, harmony, instrumentation, articulation, and production—not restate the general composition guidelines.
