## Renderer coverage

- All four final candidates use the local GeneralUser GS SoundFont through FluidSynth.
- No candidate uses SFZ because no sfizz backend is currently installed and verified.
- No external VST, Ableton, cloud generator, or invented instrument resource was used.
- The Galgame clean guitar is an explicit GM Clean Electric Guitar approximation; other desired roles were mapped to the closest available GeneralUser GS preset documented in each `instrument_notes.md`.
