# When the Horizon Answers

An original 3:36 instrumental emotional-rock composition created with the project's instrument-aware and Long-Form Phrase Planning systems.

Listen to `output/final.wav`. The complete Standard MIDI File is `output/full_song.mid`; standalone instrument files are under `tracks/`, and real rendered stems are under `stems/`.

The 16-bar Bridge contains no Lead Guitar. Rhythm Guitar, Bass, Organ, Drums and Strings carry a two-stage relay into the transformed Final Chorus.
