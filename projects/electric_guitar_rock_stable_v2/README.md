# Lanterns Against the Rain

An independently composed 96-bar emotional instrumental rock track using the formal
`legacy_stable` Lead Guitar path. The sixteen-bar Bridge Relay contains no Lead Guitar; organ,
strings, bass, rhythm guitar and drums carry the build into the highest-energy Final Chorus.

Listen to `output/final.wav` and open `output/full_song.mid` for the combined MIDI. Individual
MIDI files live under `tracks/`; isolated renders live under `stems/`. See `musical-brief.md`,
`energy-map.md`, `instrument-notes.md`, `critique.md` and `final-validation.md` for the auditable
workflow from V1 through V3.

The sound is a local GeneralUser GS preview rendered with FluidSynth. It does not claim Ample or
VST guitar playback and contains no vocals.
