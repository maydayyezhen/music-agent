# Eight Slots, One Hand

An original eight-bar acoustic-guitar strumming fragment created from
`skills_v2/acoustic_strumming/SKILL.md`.

## Constraints

- acoustic guitar only
- 4/4, 96 BPM
- continuous eighth-note D/U hand clock across every barline
- full, partial, ghost and air actions
- related two-bar variations rather than independent random bars
- no finished-song pattern used as a template

`action_grid.json` is authoritative. MIDI and WAV are derived previews.
