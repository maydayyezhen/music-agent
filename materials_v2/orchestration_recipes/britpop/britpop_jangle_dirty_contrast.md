# Britpop Jangle Dirty Contrast

## Identity

A guitar-layer contrast family that combines a cleaner, ringing or jangly role with a dirtier supporting role.

The goal is not simply `clean verse -> distorted chorus`. The useful idea is that two different guitar surfaces can carry different musical functions inside the same song or section.


## Core principle

Treat tone as part of **role separation**.

Possible division:

```text
clean / ringing guitar
-> note definition
-> partial chords
-> recurring upper figure
-> open-string continuity

rougher / overdriven guitar
-> chord mass
-> sustained midrange body
-> section weight
-> emphatic arrivals
```

The layers do not need to be active at the same time.

## Section uses

Possible behaviors include:

```text
thin clean verse
-> dirty layer enters only at selected arrivals

clean recurring motif persists
-> overdrive bed enters for larger section

rough rhythm section
-> jangly upper layer adds definition instead of more distortion
```

Choose based on the song's energy and texture plan.

## Interaction with melody

If the main melody occupies the upper-mid register, keep the jangly layer sparse or move it below / between melodic phrases.

A dirty guitar bed may provide weight without adding many new pitches. This can preserve foreground clarity while still increasing section size.

## Timbre versus composition

This recipe can be approximated with generic MIDI patches for arrangement testing, but realistic validation requires a suitable guitar renderer / amp chain.

With a neutral GM render, judge:

```text
entry / exit timing
register separation
rhythmic complement
note density
role continuity
section contrast
```

Do not judge final amp character from a weak generic patch.

## Failure modes

Revise when:

- clean and dirty layers play identical material throughout;
- `dirty` is used as a synonym for `chorus`;
- the clean layer is so busy that it becomes a second lead;
- the dirty layer adds note complexity instead of useful body;
- every section adds both layers and loses contrast;
- tone differences are expected to rescue weak role design.

## Study provenance

Promoted from the Britpop source study and practical guitar-source synthesis. It keeps the reusable idea of **ringing-definition layer versus rougher-support layer** while omitting source riffs, exact tones and artist-specific chains.
